Run it

NimbusOS runs in QEMU (on a Mac: brew install qemu). Boot the live CD with a blank 60 MB disk to install onto:

truncate -s 60M disk.img
qemu-system-x86_64 -m 256M -vga std \
  -audiodev coreaudio,id=snd0 -device AC97,audiodev=snd0 \
  -nic user,model=e1000 \
  -cdrom nimbusos-{{VERSION}}.iso -boot d \
  -drive file=disk.img,format=raw,index=0

On Linux use -audiodev pa,id=snd0 (or none). Inside NimbusOS, open Install NimbusOS to put it on the disk; afterwards boot with -boot c.

What's inside

Desktop

Draggable windows, taskbar, Start menu, File Explorer, Notepad, Paint with a transparent pen and canvas sizes up to 4K, Calculator, Terminal, Settings, a shared clipboard, and custom pointers.

Games & media

Minesweeper, Snake, Solitaire, Block Runner, Breakout, and a Media Player with AC'97 sound.

Internet

Its own TCP/IP stack and a TLS 1.3 client. The Web Browser opens http:// and https:// pages, understands core CSS, and searches the web from the address bar.

Programs

Ring-3 user programs with their own C library, system calls and ELF loader.

Smooth text

Anti-aliased DejaVu Sans in regular and bold, with larger headings in the browser.

Nimbus Update

Signed updates from this site, with two kernel slots so an update can't break booting.

From scratch

Bootloader, 64-bit kernel, drivers, file system and GUI: no existing kernel, libc or GUI library.

Updates

Installed systems check this site with Nimbus Update (Start menu, or update in the Terminal). Every release is signed with Ed25519, so NimbusOS only installs updates from its publisher.
